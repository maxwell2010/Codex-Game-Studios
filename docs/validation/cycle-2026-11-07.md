# Codex studio lifecycle validation - 2026-11-07

## Result and scope

PASS for one minimal-rigor, offline Godot 4.5.1 / GDScript game: Coin Collector.
Executed by Codex in the current chat using explicit skill/document reads and
real shell/engine tools. Studio roles were handled sequentially. This is not a
claim that all 74 workflows or 49 native subagents were exercised, nor a test of
automatic skill discovery in a fresh Codex client. Unity, Unreal, multiplayer,
store publishing and standalone executable exports were not tested.

The release is a **source distribution requiring Godot 4.5.1**, not a standalone
executable. No external game store was contacted and no game release was uploaded.
The test harness repeats observable lifecycle operations; it does not call an LLM
or recreate the reasoning steps of the skills. The fixture is retained in Ready
state so each replay exercises state changes anew. Completed run artifacts are
in the isolated scratch directory and the retained evidence below.

## Defects found and fixed

1. **Missing skill resources:** the original adapter omitted 112 supporting
   Markdown files. Engine setup, prototypes, reviews and other workflows stopped
   at missing references. All resources are now adapted and copied.
2. **Wrong reference base:** the workflow was nested under references/, making
   its own references/ paths ambiguous. It now lives beside SKILL.md, preserving
   the original resource layout; bridge instructions state the base directory.
3. **Missing engine setup targets:** AGENTS.md lacked the Technology Stack and
   Engine Version Reference sections expected by setup. Added explicit read
   guidance without relying on Claude @ imports or replacing project rules.
4. **Weak regression coverage:** previous tests checked wrapper packaging only.
   Added supporting-resource parity, local-link integrity, link/path escape,
   no-command-execution and actual engine lifecycle regression checks.
5. **QA timing:** the new test initially read input state before Godot had
   processed it and omitted key releases. The runner now waits for processing
   and releases keys, checking real input dispatch rather than calling handlers.
6. **Fixture code-root mismatch:** moved gameplay into src/ so project-state and
   audit helpers see real source files rather than an empty default code root.
